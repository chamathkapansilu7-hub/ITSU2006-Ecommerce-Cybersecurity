# Issue Management Strategy

## Purpose
Track current impediments separately from uncertain future risks. Use Jira to record real academic-work issues and this register for hypothetical project issue-management design.

## Proposed workflow
Identify → log → prioritise → assign → investigate → resolve → verify → close.

| Severity | Example | Response approach |
|---|---|---|
| Critical | Hypothetical production payment outage | Immediate escalation in simulated project |
| High | Risk document conflicts with approved scope | Project-lead review before sign-off |
| Medium | Missing source or review comment | Assign owner and due date |
| Low | Formatting inconsistency | Correct in next document review |

## Issue log template
Issue ID; description; date raised; severity; owner; impact; decision; action; status; closure date.

Do not misrepresent simulated incidents as actual security incidents.
