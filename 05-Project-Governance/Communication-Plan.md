# Communication and Stakeholder Engagement Plan

| Audience | Information | Proposed frequency | Channel | Owner |
|---|---|---|---|---|
| Project team | Task progress, blockers, next actions | Weekly and as needed | Jira board / group meeting | Project leader |
| Team members | Document changes and review requests | At each meaningful update | GitHub commits / pull requests | Document author |
| Academic supervisor | Milestone status, major scope changes | At course checkpoints | LMS or approved contact method | Project leader |
| Simulated business sponsor | Decisions, risk priorities, approval requests | At stage gates (simulation) | Planned status report | Project leader |

## Meeting notes format
Date; attendees; decisions; open actions; owner; due date; next meeting. Never claim fictional simulated sponsor meetings as actual meetings.

## Escalation
Blocker → task owner → project leader → academic supervisor where appropriate. Major scope changes use the change request log and traceable GitHub revision.
