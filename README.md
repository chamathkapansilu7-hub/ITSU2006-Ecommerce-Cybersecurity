# ITSU2006 – E-Commerce Cybersecurity Project Management

## Project Overview
This repository contains academic project management documentation for a proposed Cybersecurity Risk Assessment and Mitigation Strategy Implementation project for an e-commerce platform.

**Project Type:** Academic project planning simulation  
**Project Duration:** 12 weeks (2 November 2026 – 22 January 2027)  
**Project Team:** Four members  
**Project Management Tools:** Jira and GitHub

## Project Objectives
- Identify critical e-commerce information assets and potential cybersecurity threats.
- Develop a structured cybersecurity risk assessment and prioritisation approach.
- Propose appropriate mitigation strategies and security controls.
- Prepare a detailed project charter, scope, WBS, schedule and resource plan.
- Establish risk, issue, change, quality and communication management procedures.

## Project Deliverables
1. Project Charter and Stakeholder Register
2. Scope Statement and Work Breakdown Structure
3. Gantt Chart and Resource Allocation Plan
4. Cybersecurity Risk Assessment and Risk Register
5. Risk Mitigation and Security Control Plan
6. Change and Configuration Management Plan
7. Quality, Communication and Testing Plans
8. Final Academic Report and Group Presentation
